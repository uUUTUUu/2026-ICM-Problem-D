# 2026 美国大学生数学建模竞赛（ICM）Problem D

**论文题目：** *Steering the Fever: A Smarter, Safer Path to Wins and Value via Rolling MPC*  
**参赛编号：** 2605710

## 项目简介

本项目以美国女子职业篮球联赛（WNBA）的 **Indiana Fever** 球队为研究对象，探讨如何在工资帽、阵容规模和财务约束下，协调球队的竞技表现、球迷关注度与长期商业价值。

我们将球队经营视为一个具有多目标、动态反馈和外部不确定性的决策问题，构建以**滚动模型预测控制（Model Predictive Control，MPC）**为核心的优化框架，并将阵容配置、联盟扩军、球员伤病和门票定价纳入统一的分析思路。

## 实现思路

### 1. 状态空间建模与滚动 MPC

将球队经营状况抽象为三个状态变量：**竞技实力、球迷热度和财务状况**；将**财务杠杆、工资帽使用率、明星球员比例和营销投入**作为可调节的控制变量。

用离散时间状态空间模型描述管理决策与球队状态之间的关系：

$$
X_{t+1}=AX_t+BU_t
$$

在每个决策窗口预测未来多个阶段的表现，在实际约束下优化控制序列，仅执行当前阶段决策，再利用更新后的球队状态重新优化，形成滚动反馈过程。

### 2. 双层决策与球员阵容优化

上层 MPC 确定球队整体经营目标，例如薪资投入强度和明星球员比例；下层构建**0–1 整数优化模型**，从自由球员和新秀候选池中选择阵容。

下层在兼顾球员综合价值与薪资成本的同时，满足工资帽、阵容人数、位置结构等限制，并将阵容选择结果反馈到球队状态模型，实现从**宏观管理策略到具体球员决策**的衔接。

### 3. 联盟扩军的扰动与情景分析

将联盟扩军视为影响球队经营状态的**时变外部扰动**，分析不同扩军地点带来的市场竞争、联赛增长、出行负担和球员资源变化。

在基础状态方程中加入扰动项，并相应调整收入、成本等环境参数；随后重新运行 MPC，研究球队如何根据外部环境变化调整经营策略。

### 4. 球员伤病与风险决策

将关键球员受伤建模为作用于球队状态的外部冲击，分别估计竞技表现变化以及门票、媒体和商品销售等渠道的经营影响。

针对**短期缺阵**和**长期缺阵**等不确定情景，结合**均值—方差优化**权衡预期表现与风险，再由 MPC 动态调整杠杆、薪资投入和营销决策。

### 5. 动态票价优化

进一步将**门票价格**加入控制变量，通过**需求价格弹性**描述票价对上座需求及门票收入的影响。

将票价决策纳入滚动优化框架，得到分阶段调价方案，并根据后续上座率及球队状态变化重新评估和调整。

## 主要方法

- 离散时间状态空间建模
- 模型预测控制（MPC）与滚动时域优化
- 多目标约束优化
- 0–1 整数规划与双层决策
- 外部扰动建模和情景分析
- 均值—方差风险优化
- 需求价格弹性与动态定价
